% ── Problem Description ───────────────────────────────────────────────────────
\section*{Problem Description}

Consider a \textbf{binary classification} problem with labels:
\[
  y \in \{0, 1\}.
\]

You are given a single input sample:
\[
  \mathbf{x} = \begin{bmatrix} 1 \\ 2 \end{bmatrix} \in \mathbb{R}^2.
\]

The model is a \textbf{Multi-Layer Perceptron (MLP)} with:
\begin{itemize}[topsep=2pt, itemsep=2pt]
  \item One hidden layer (ReLU activation),
  \item One output neuron (Sigmoid activation).
\end{itemize}

% ── Model Specification ───────────────────────────────────────────────────────
\section*{Model Specification}

\subsection*{Hidden Layer}

\[
  \mathbf{a}^{(1)} = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)}, \qquad
  \mathbf{h} = \ReLU\!\left(\mathbf{a}^{(1)}\right)
\]

where
\[
  W^{(1)} = \begin{bmatrix} 1 & -1 \\ 0.5 & 0.5 \end{bmatrix}, \qquad
  \mathbf{b}^{(1)} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}.
\]

\subsection*{Output Layer}

\[
  z = W^{(2)}\mathbf{h} + b^{(2)}, \qquad
  \hat{y} = \sigma(z), \qquad
  \sigma(z) = \frac{1}{1 + e^{-z}}
\]

where
\[
  W^{(2)} = \begin{bmatrix} 1 & 1 \end{bmatrix}, \qquad b^{(2)} = 0.
\]

% ── Loss Function ─────────────────────────────────────────────────────────────
\section*{Loss Function}

Binary Cross-Entropy loss:
\[
  \mathcal{L}(y,\,\hat{y}) = -\left[y \log \hat{y} + (1 - y)\log(1 - \hat{y})\right].
\]
